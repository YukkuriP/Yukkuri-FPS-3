# Yukkuri Fleet Simulator

アーレイ・バーク級 Flight IIAを参考にした、非戦闘の艦艇生活・航海ロールプレイシミュレーターです。実艦の兵器運用、戦闘システム、戦術手順は再現しません。

## 開発環境
- Godot 4.7.2（Compatibility renderer）
- Blender 4.x（外観アセット制作）
- Windows 11。管理者権限不要のユーザー領域またはUSB運用を想定。

## 参考にした公開情報
- 米海軍 DDG-51 Fact File：Flight IIAの全長・幅、乗員規模、艦級の基本情報
- Naval Sea Systems Command：実艦の見学記録（艦橋、食堂、乗員居住区）
- 米海軍 Destroyer Ship Class Info：Flight IIAの格納庫・航空運用設備の有無

公開情報で確認できない内部の全寸法・全区画配置は、実艦の図面として断定しません。ゲーム内の通路・部屋配置は歩行可能なシミュレーター向け補完設計です。

## 起動
Godot 4.7.2で `project.godot` をインポートして実行してください。

## 操作
- WASD：艦内移動
- マウス：視点操作
- Esc：マウスカーソル切り替え
- 1～6：担当ロール切り替え
- 3Dコンソール画面をクリック：架空の航海・機関・通信・艦内サービス表示を操作

## 現在の構成
- `scripts/deck_plan.gd`：部屋を区画化した歩行可能なデッキ、中央通路、6か所の自動扉、隔壁、照明、家具、主要設備の衝突形状
- `scripts/main.gd`：プレイヤー移動、ロール切替、3Dモニター、架空の航海・艦内状態
- `scripts/visual_upgrade.gd`：閉じたテーパー船体メッシュ、生成法線、船体外部ディテール
- `tests/ship_smoke_test.gd`：艦体寸法スケール、船体メッシュ、扉数、衝突形状、プレイヤー着地の実行時テスト
- `blender/generate_ship.py`：Blender用の外観モデル生成スクリプト

## 寸法基準と検証
- Flight IIAの公表全長：155.29 m
- 公表幅：18.0 m
- ゲーム内の船体・デッキ・艦内区画は長手方向を2倍にして、全長基準に合わせています。
- Blender生成スクリプトも同じ長手方向スケールを使用します。

Godot 4.7.2用CIでは、プロジェクトのインポート・構文解析、ヘッドレス起動、艦体メッシュ・区画扉・衝突形状・プレイヤー着地のスモークテストを実行します。公開資料にない実艦内部の完全な一般配置図や寸法は推測で断定しません。CI成功と実機での全区画の目視確認は別の検証項目です。
