# Yukkuri Fleet Simulator

アーレイ・バーク級をモチーフにした艦艇ロールプレイ／シミュレーターの新規プロジェクトです。

## 開発環境
- Godot 4.x
- Blender 4.x
- Windows 11（管理者権限なしのユーザー領域での利用を想定）
- 描画方式：Compatibility（幅広いGPUでの動作を優先）

## 起動
1. Godot のポータブル版をユーザー領域またはUSBに展開
2. Godot Project Managerから、このフォルダの `project.godot` をインポート
3. 実行

## 現在の操作
- WASD：移動
- マウス：視点操作
- E：端末操作（仮表示）
- 1～5：役職切り替え
- Esc：マウスカーソル解放
