# Yukkuri Fleet Simulator

アーレイ・バーク級をモチーフにした架空の艦艇ロールプレイ／航海シミュレーター。艦内生活・航海管理・部署の仕事を体験するゲームで、実在艦の兵器操作や戦闘手順は再現しません。

## 環境
- Godot 4.7.2（Compatibility renderer）
- Blender 4.x（外観モデル生成用）
- Windows 11。管理者権限不要のユーザー領域またはUSB運用を想定。

## 起動
Godotのポータブル版を展開し、Project Managerから `project.godot` をインポートして実行。

## 操作
- WASD：艦内移動 / マウス：視点
- Esc：マウスカーソルの表示／非表示を切り替え
- マウスで3D空間の各コンソール画面を直接クリックして操作（別画面は開かない）
- 1～6：艦長、操舵員、CIC士官、機関員、通信員、乗組員

## 現在の実装
海面・空・船体・艦橋・マスト・格納庫・甲板設備、艦内の各部署を区別する内装、艦橋の操舵輪・計器類、CICの大型表示壁と作業卓、通信ラック、機関設備、乗員区画、常時稼働する3Dモニター。航海・機関・通信・艦内サービスの架空データは共通状態から更新され、画面や操舵輪を3D空間内で直接クリックして操作できます。

## Blender外観アセット
`blender/generate_ship.py` をBlenderのScriptingワークスペースで実行すると、船体外観のblend/glbをスクリプトの相対保存先に出力します。

## 検証状況
Godot 4.7.2での実機起動・描画・入力テストは、この更新環境ではまだ実施できていません。完成度や動作を保証するものではありません。
